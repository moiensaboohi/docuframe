# slides-classic — Classic slides

**What it is:** Clean presentation slides: white pages, a left-aligned header with a short blue bar, simple grey cards, plain photos, page numbers, hard cuts between slides.

**Use for:** lessons and courses, work and business explainers, step-by-step how-tos.
**Avoid for:** Cinematic storytelling.

**Recipe:** motion = rise, source = quiet, lower_third = line, accents = none, panel = surface, photo = rounded, title = kinetic, number = counter, layout = deck, align = start, flat = True, shadow = 0.0.

**Judge a still by:**
- One hero per beat; everything else quieter.
- Type never touches the frame edge; nothing important in the bottom 20% of a 9:16 frame.
- Colours come only from this pack's tokens; numbers always carry their source.
- Motion lands on the spoken word, then holds still long enough to read.
