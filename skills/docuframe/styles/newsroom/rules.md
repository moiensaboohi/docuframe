# newsroom — Newsroom bulletin

**What it is:** Broadcast-news clarity: crisp light ground, heavy red title bars, framed photos, source chips and lower thirds, hard cuts.

**Use for:** news explainers, current affairs, fact-checks.
**Avoid for:** Slow, reflective essays.

**Recipe:** panel = card, photo = frame, title = bar, number = bar, motion = slide, accents = none, source = chip, lower_third = bar, shadow = 0.0.

**Judge a still by:**
- One hero per beat; everything else quieter.
- Type never touches the frame edge; nothing important in the bottom 20% of a 9:16 frame.
- Colours come only from this pack's tokens; numbers always carry their source.
- Motion lands on the spoken word, then holds still long enough to read.
