# case-file — True-crime case file

**What it is:** A detective's desk: manila folder ground, Polaroids, typewritten labels on torn paper, red stamps and red string between clues.

**Use for:** true crime, mysteries and cold cases, heists and scandals.
**Avoid for:** Anything light-hearted.

**Recipe:** panel = paper, photo = polaroid, title = torn, number = counter, motion = drop, accents = none, source = plain, lower_third = bar, strings = True, shadow = 0.35.

**Judge a still by:**
- One hero per beat; everything else quieter.
- Type never touches the frame edge; nothing important in the bottom 20% of a 9:16 frame.
- Colours come only from this pack's tokens; numbers always carry their source.
- Motion lands on the spoken word, then holds still long enough to read.
