# swiss-grid — Swiss grid

**What it is:** International-style minimalism: off-white page, strict left alignment, tight bold sans headlines, light oversized numbers, hairline rules and one red accent.

**Use for:** design, architecture and art, economics and data, essays with a clear argument.
**Avoid for:** Kids' content.

**Recipe:** motion = rise, source = quiet, lower_third = line, accents = none, panel = none, photo = plain, title = kinetic, number = counter, layout = editorial, align = start, shadow = 0.0.

**Judge a still by:**
- One hero per beat; everything else quieter.
- Type never touches the frame edge; nothing important in the bottom 20% of a 9:16 frame.
- Colours come only from this pack's tokens; numbers always carry their source.
- Motion lands on the spoken word, then holds still long enough to read.
