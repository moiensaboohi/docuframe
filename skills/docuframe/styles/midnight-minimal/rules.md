# midnight-minimal — Midnight minimal

**What it is:** Quiet dark interface look: deep blue-black ground, crisp white type, mint accents, hairline-edged surfaces and left-aligned compositions.

**Use for:** technology and software, science and space, finance and data.
**Avoid for:** Rustic or archival subjects.

**Recipe:** motion = rise, source = quiet, lower_third = line, accents = none, panel = surface, photo = rounded, title = kinetic, number = counter, layout = editorial, align = start, hairline = True, wrap = False, shadow = 0.0.

**Judge a still by:**
- One hero per beat; everything else quieter.
- Type never touches the frame edge; nothing important in the bottom 20% of a 9:16 frame.
- Colours come only from this pack's tokens; numbers always carry their source.
- Motion lands on the spoken word, then holds still long enough to read.
