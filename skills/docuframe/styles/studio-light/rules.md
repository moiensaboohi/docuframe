# studio-light — Studio light (keynote minimal)

**What it is:** Product-keynote calm: soft light-grey stage, centred tight headlines in a modern sans, lots of air, photos with rounded corners, every element rising in with a soft blur.

**Use for:** technology and products, business and strategy, clean explainers of any kind.
**Avoid for:** Gritty true crime and archive-heavy history.

**Recipe:** motion = rise, source = quiet, lower_third = line, accents = none, panel = none, photo = rounded, title = kinetic, number = counter, layout = editorial, align = center, eyebrow_sub = True, shadow = 0.0.

**Judge a still by:**
- One hero per beat; everything else quieter.
- Type never touches the frame edge; nothing important in the bottom 20% of a 9:16 frame.
- Colours come only from this pack's tokens; numbers always carry their source.
- Motion lands on the spoken word, then holds still long enough to read.
